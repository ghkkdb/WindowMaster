# WindowMaster

WindowMaster 是面向 Windows 10/11 的轻量窗口增强工具。它可以管理当前桌面窗口、调整透明度和置顶状态、快速分屏，并保存或恢复多套工作布局。

## 功能

- 搜索并定时刷新可管理的顶级窗口，同时保留当前选择。
- 双击窗口列表中的任意一行，可恢复最小化窗口、请求前台激活并闪烁窗口和任务栏按钮。
- 调整窗口不透明度（30%–100%）、切换置顶、左右分屏和最大化。
- 一键最小化当前全部可管理程序窗口。
- 每个显示器最多保留一个由当前可管理窗口构成的置顶项；置顶新窗口时自动取消同屏旧置顶窗口，其他显示器不受影响。
- 使用当前窗口所在显示器的工作区，支持任务栏、负坐标和不同 DPI。
- 保存、覆盖、恢复和删除多套命名布局。
- 按进程名及 exact、glob、regex 或 process-only 标题规则一对一匹配窗口；多候选不再静默选择，而是标记为冲突。
- 恢复前生成不可变 `RestorePlan` 并显示可执行、跳过和冲突摘要；确认后才移动窗口，预览后显示器拓扑变化会中止执行。
- 可选系统托盘：关闭主窗口时继续后台运行；托盘菜单支持显示主窗口、刷新、选择布局进入恢复确认流程和明确退出。
- 监听显示器插拔和分辨率变化，等待配置稳定后在托盘提示匹配布局；点击提示仍会先显示恢复预览，不会自动移动窗口。
- 原生全局快捷键，无需管理员权限：
  - `Ctrl+Alt+T`：切换当前前台窗口置顶；WindowMaster 位于前台时改为操作列表选中窗口。
  - `Ctrl+Alt+1`：前台窗口移动到左半屏。
  - `Ctrl+Alt+2`：前台窗口移动到右半屏。
  - `Ctrl+Alt+M`：最小化全部可管理程序窗口。
- 顶部“快捷键设置”标签可打开编辑窗口，支持启用、禁用和修改以上全局快捷键；冲突或保存失败时自动恢复旧绑定。

## 环境与运行

需要 Windows 10/11 64 位和 Python 3.11 64 位。

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

布局保存于 `%APPDATA%\WindowMaster\layouts.json`。配置使用强类型 v2 模式并以原子替换方式写入；检测到 v1 文件时会先保存 `layouts.v1-backup-时间.json`，再自动迁移。配置损坏或嵌套字段无效时，程序会将其重命名为 `layouts.corrupt-时间.json`，然后使用空配置继续启动。

## 测试

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m compileall -q main.py core ui utils tests
```

自动化测试使用 Mock 隔离窗口操作。多显示器、不同 DPI、快捷键冲突以及受保护窗口需要在目标机器上进行人工验收。

## 打包

```powershell
pyinstaller --noconfirm --clean WindowMaster.spec
```

输出位于 `dist\WindowMaster\WindowMaster.exe`。项目采用单目录、无控制台窗口打包方式。若安全软件拦截全局快捷键或窗口控制，请将构建目录加入可信列表；操作高权限进程窗口时，Windows 可能拒绝访问，这是系统权限边界。

## 系统托盘

系统托盘默认启用。主窗口顶部“设置”标签和托盘右键菜单都提供设置入口；当前设置窗口包含“关闭时隐藏到系统托盘”选项。启用后，点击窗口关闭按钮只会隐藏主窗口，全局快捷键和定时刷新仍然有效。双击托盘图标可重新显示主窗口；右键菜单可刷新、恢复布局、打开设置或真正退出程序。该设置会保存到配置文件；系统不支持托盘时会自动禁用。

启用托盘后，WindowMaster 会监听显示器插拔和分辨率变化，并按 `display_change_debounce_ms` 等待系统状态稳定。若只有一个布局与当前显示器拓扑匹配，点击通知会进入该布局的标准预览和确认流程；若存在多个匹配布局，则打开主窗口供用户选择。新保存的布局记录完整显示器拓扑，旧版布局会按窗口中已有的显示器设备名和工作区兼容匹配。

## 当前边界

- 不包含自启动、自动更新或目标窗口隐藏。
- 恢复布局时不会启动缺失的应用，只处理当前已打开的窗口。
- 某些系统窗口、UWP 隐藏宿主或更高权限窗口可能无法枚举或控制。
